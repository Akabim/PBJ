## Catatan status

- Diagram Abim menjelaskan sistem networking pada branch `programmer/systems`. Relay M3 ditandai sebagai rencana di dokumen sumbernya.
- Diagram Ibnu menjelaskan hubungan script dan scene di branch mechanics.
- Diagram Aul, Linda, dan Nesya adalah peta pengelompokan aset. Diagram itu tidak mengklaim bahwa semua art/audio sudah terhubung ke scene atau script.
- Dokumen ini tidak mengubah scene, prefab, script gameplay, atau aset art/audio; hanya dokumentasi diagram.
